# Linus · L0x3n

My portfolio as a vibecoder: games, desktop apps, web products and AI pipelines, all built by directing AI coding agents.

**Live:** https://l0x3n.github.io/

A static site with no build step:

- `index.html`, `styles.css`, `app.js`: the page
- `data/projects.js`: every project shown, with stack, numbers and highlights
- `data/activity.js`: commit activity read from git across my own repositories
- `data/site.js`: featured projects, the stack overview and the method section
- `assets/shots/`: screenshots, converted to WebP

Run it locally with any static server, for example `npx http-server .`
